# 因果图：路径、调整与潜在结果的桥梁

## 1. 先定义干预，不由回归反推图

固定单位、处理及结果时点、目标人口和总效应/直接效应；把已知共同原因、决策反馈和样本进入机制画入图，时间反馈用带时点的节点展开。箭头表示允许的直接因果渠道，缺边是需要制度或机制依据的排除承诺，不是样本相关接近零的发现。不能因变量在处理前或能预测处理就认定它适合调整。[1,2]

DAG没有有向环；真实系统有同期均衡或未明时序时，不强行画成已识别的递归模型。未观测共同原因应明确，不能靠省略节点制造可调整性。图不提供边的大小、效应符号或自动的外部有效性。[1,2]

## 2. 对每条路径判定 d-separation

路径可逆着箭头行走；内部节点若在该路径上是两箭头相碰，就是collider，角色取决于路径。给定与端点互不相交的条件集S，一条路径被阻断，当且仅当至少出现以下一种情形：

- 一个非collider在S中；
- 一个collider本身及其所有后代都不在S中。

所有路径均被阻断才是d-separation。在相应Markov因果模型下它蕴含条件独立；一条路径开放只是模型允许依赖，不保证任意参数化都产生非零关联或某方向偏差。条件化collider或其后代会激活该处，但路径仍可能在别处被阻断。[2, Definition 1]

例如D←U→Y在U被调整时阻断；D→M←U→Y原本在M处关闭，调整M或其后代可能将其打开。行政记录要求S=1、失访后只保留响应者、按将来结果选样本，同样属于条件化；应将这个选择节点纳入目标和路径分析。[1,2]

## 3. 经典 backdoor 是充分工具，不是所有识别的必要条件

对D到Y的总效应，经典准则要求S不含D的后代，且阻断每条从D出发、首边指向D的路径。D→M←Y虽是非因果路径，不属于这个严格定义的backdoor。须核整个条件集和全部路径，不能只数控制变量或逐个判断变量“好坏”。[2, Definition 3]

若结构假设可信、一致性成立且目标支点有相应处理支持，令m_d(s)=E[Y|D=d,S=s]，则

    E[Y(d)] = ∫ m_d(s) dF_target(s).

ATE使用同一目标人口的S分布；ATT的反事实标准化使用实际treated分布并核相应单侧支持。图提供调整的识别依据，不等于任意线性OLS的D系数已经是ATE；函数形式、异质性和实际权重还要审。[2, Eq.25；另见matching-weighting-audit.md]

## 4. 图与潜在结果如何衔接

在给定SCM中，把处理方程替换为D=d，保持同一背景u，得到Y(d,u)；一致性把实际处理下的潜在结果连接到观察Y。在可信模型下，有效backdoor集可支持Y(d)与D的相应条件可交换性。图组织机制/排除，潜在结果组织反事实目标；两种语言互补，均不免除支持及估计/推断条件。[2, Definition 6、§5.3]

不要为总效应机械调整中介。条件化M=m与干预do(M=m)不同，既可能截断中介路径，也可能开放其他路径；控制前后系数变化不是机制分解的证明。直接/间接效应的额外条件另读[中介参考](mediation-estimands-audit.md)，分派与人群目标另读[潜在结果参考](potential-outcomes-assignment.md)。[1,2]
