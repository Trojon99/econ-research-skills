# Figure Design Reference

## Match the figure to the empirical question

| Empirical question | Preferred figure |
|---|---|
| Do treatment and comparison groups move similarly before policy? | Two-line or event-time trend plot |
| Does a baseline-risk gap change after policy? | Four-line group plot or gap-over-time plot |
| Are exits concentrated in school-break months? | Month-of-year lines for raw exit, return, completion, cleaned dropout |
| Is a first stage visible? | Coverage/exposure trend by treatment status |
| Are subgroup patterns heterogeneous? | Faceted trend plots |
| What does one-time baseline composition look like? | Dot/bar plot; table only if exact values are central |
| Is attrition differential? | Follow-up share plot by baseline group |
| Are topical-module measures comparable over waves? | Wave-specific prevalence/mean trend |

## Diagnostic versus paper figures

Create diagnostic figures liberally when they help detect data or design problems. Keep publication figures selective.

A diagnostic figure may show:
- raw and cleaned definitions together;
- unresolved or missing categories;
- cell counts or support warnings;
- alternate age windows or timing definitions.

A paper figure should usually answer one substantive question cleanly and avoid unnecessary series.

## Graph-first hierarchy for empirical projects

A typical order is:

1. Main outcome by treatment/comparison group.
2. First stage or exposure outcome.
3. Main baseline-risk heterogeneity.
4. Transition/seasonality diagnostics.
5. Raw DID/DDD gap evolution.
6. Selected subgroup heterogeneity.
7. Mechanism-related descriptive patterns.
8. Attrition/support diagnostics.

Do not force all eight categories when they are irrelevant.

## Tables that remain useful

Use tables when exact values matter more than visual pattern:

- conventional baseline Table 1;
- sample counts by design cell;
- timing/variable-source audit;
- compact descriptive appendix;
- exact coefficients and standard errors.

If a table merely repeats a figure, omit it unless the user explicitly asks for exact values.
