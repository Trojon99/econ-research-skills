# 潜在结果、选择与分派型推断

## 1. 同一人群的两个状态

明确单位、处理版本/强度、时点、结局和目标人口。二元处理的一致性关系为Y=D Y(1)+(1−D)Y(0)。令δ=Y(1)−Y(0)，ATE=E[δ]、ATT=E[δ|D=1]、ATU=E[δ|D=0]；后两者按实际处理状态划分，不是IV的潜在依从类型。均值效应在维护假设下可以识别，不意味着恢复每人的两个结果或个体效应分布。[1, §§4.1.1–4.1.3]

SUTVA不要求δ齐一：处理定义须避免影响结果但未明确的隐藏版本，并审单位间干扰。相同名义剂量不是版本一致的充分条件；大规模扩张若改变价格、网络或环境，需要改写暴露/反事实，而非默认小规模效应可移植。一般均衡是干扰/政策外推的实质问题，不另造一条机械SUTVA定义。[1, §4.1.5]

## 2. 观察差异包含什么选择

令π=P(D=1)，0<π<1，均值存在，S=E[Y(0)|D=1]−E[Y(0)|D=0]。总体简单差为

    Δobs = ATT + S
         = ATE + S + (1−π)(ATT−ATU).

同一差值相对ATT和ATE有不同分解；效应异质本身不是实验偏误。两项偏误可能抵消，估计接近某benchmark不能认证各项为零。S通常不可由观测结果直接计算。[1, §4.1.3]

D独立于收益δ，比独立于(Y(0),Y(1))弱：恒定收益仍可存在基线选择。不能把“没有按收益选”当作随机分派，或把全人口有行政记录当作反事实齐全。[1, §4.1.4；此处是逻辑边界，不依赖教材脚注的等价说法]

## 3. 随机的是哪一步

固定有限人口、固定处理人数的等概率完全随机分派下，均值差在分派分布下对有限人口ATE无偏；一次分派仍可能不平衡，个体效应仍可异质。Bernoulli、分层、配对、簇随机是不同机制；不等概率设计须匹配其目标及估计权重，不能普遍照用未加权均值差。[1；2, §3.2、§4.2]

随机offer不使实际take-up随机；ITT是分派/鼓励的效应，接受处理的IV解释另需排除、相关性、单调等。观察到结果的响应者也未必仍是随机可比样本；报告分派、接受及结局观测三个分母。抽样不确定性和反事实/分派不确定性不同，完整观察目标人口也不将后者归零。[1；2]

## 4. Fisher检验的可复核构造

sharp zero null是每单位Y_i(1)=Y_i(0)，强于ATE=0。仅在该null下补全潜在结果。指定真实分派支持Ω及概率p(a)，将统计量写为T(a,Y_null)，按上尾的一个定义计算

    p_upper = Σ_{a∈Ω} p(a) 1{T(a,Y_null) ≥ T(a_obs,Y_obs)}.

等概率才化为计数除以|Ω|。双侧若选择绝对值统计量，则比较|T|；它不必等于把任意单侧p乘二。明确ties用≥、原分派是否纳入、sharp null、尾部及可允许集合；按排序位置取尾数可能漏计并列。[1, §4.2；2, §4.1]

分层在层内重分、簇分派重分整个簇，不能任意逐行shuffle。全枚举得到指定有限空间的null分布；抽取分派的Monte Carlo近似须报告抽法、次数、随机种子和p值估计约定，不假装已穷举或无数值误差。统计量/子组/窗口可以探索，但若根据结果选择检验，须在解释中纳入选择或多重检验问题，不强制所有探索事前预注册。[1,2]

均值差、秩差和分布统计量回答不同偏离，功效不普遍排序。秩有ties时声明如midranks的规则；KS比较经验CDF而不是核密度曲线。p值是null与设计下的尾概率，不是null为真的后验概率。弱均值零假设的推断不能直接用sharp-zero补全规则认证。[1, §4.2；2, §§4.1–4.2]
