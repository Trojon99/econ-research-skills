# External data provenance: from a source record to an analysis row

Use this when a public indicator, paper, filing or text score is about to become evidence. A reviewer should be able to start with one reported value, find the source object **as it was available at the relevant date**, and reproduce its selection. A URL alone cannot show why that particular record was used.

## Record the acquisition

Keep one receipt per request or release, including failed and deliberately capped requests. Record the provider and original producer, dataset and version, stable IDs, requested entities and dates, endpoint or catalogue URL, non-secret filters, ordering, page range, retrieval time with zone, rights for storage and redistribution, and the expected unit and key. For permitted snapshots, save the original response and its digest before reshaping; give each refresh a new identity. Keep derived rows linked to the receipt. If redistribution is restricted, share the specification and permitted aggregates, not the source file. See [data lifecycle](data-lifecycle-reproducibility.md) for file placement.

Reconcile requested IDs, pages and dates with what arrived. Distinguish an absent series, a returned null, a true zero, and a request that failed. Record duplicate keys and unresolved matches before joining. A byte digest identifies a saved copy; it does not establish completeness or accuracy. If permission or coverage is unclear, record the gap and request an authorized export rather than substituting a different population.

## Public indicators: what was measured, and when was it known?

| Source | Decision before joining | Audit that can change that decision |
|---|---|---|
| FRED / ALFRED | Keep the series ID, native frequency, units, adjustment, observation window and real-time window. Choose *latest revised* or *known on a specified date* before analysis. | For a historical decision, set the real-time start and end to that decision date, then verify historical coverage. A recent download restricted to old observation dates can still contain revisions made later. If no historical vintage is available, mark the point-in-time analysis unsupported. [FRED, Real-Time Periods → Introduction](https://fred.stlouisfed.org/docs/api/fred/realtime_period.html) |
| World Bank Indicators | Identify the database/source, indicator and geography codes, period and requested frequency. Decide explicitly whether geographic aggregates belong in the sample. | Reconcile the returned page count and record total before merging. Check requested years against actual years; a most-recent nonempty value may refer to an earlier year. Record any gap filling and its source period, or leave the cell missing. [World Bank, Query Strings → Page, MRNEV, Gap-fill; Responses](https://datahelpdesk.worldbank.org/knowledgebase/articles/898581-api-basic-call-structures) |
| Data Commons | Retain entity and variable DCIDs, observation date, facet ID and the associated provenance. Check the place type and parent when a name has several candidates; do not select by list position. | Before pivoting, list facets per entity–variable–date. Some differ by producer or measurement method. Choose a documented facet or keep separate rows; do not average them to manufacture uniqueness. Compare actual dates for a latest-value cross section. [Observation v2, Query parameters; examples 9–10](https://docs.datacommons.org/api/rest/v2/observation) |

A change in frequency requires an economic rule: for example, an end-of-period stock and a sum of period flows answer different questions. Preserve the native observations, the aggregation rule and the number of contributing periods. A common date label does not make the underlying measurements comparable.

## Literature records and PDFs

1. **Search receipt.** Save database, entity searched, query text, filters, sort, date, stopping rule, declared matches, raw records and unique IDs. For OpenAlex, distinguish deliberate top-*k* selection from an exhausted search. Record the continuation state and terminal response; an interruption is not exhaustion. Use the provider's snapshot for whole-database work rather than paging the entire index. [OpenAlex, Cursor paging](https://developers.openalex.org/guides/page-through-results).
2. **Screening record.** For a formal review, freeze eligibility criteria, link every database record to its report and each report to the underlying study, and retain stage and reason for exclusion. Reconcile records found, duplicates, reports sought but not retrieved, full texts excluded and studies included, with the unit stated at each stage. Do not count two versions as independent studies, or mark an inaccessible report ineligible on substantive grounds. [PRISMA 2020, flow diagram and template selection](https://www.prisma-statement.org/prisma-2020-flow-diagram).
3. **Evidence record.** Crossref's `/works/{doi}` gives a deposited metadata record, not a verification of a result. Match title, authors and version against the document actually used. Keep draft and publication locators separate if the table, estimate or pagination differs. If the PDF is unavailable, retain the bibliographic match and mark the relevant claim unverified. [Crossref, REST API → Endpoints](https://www.crossref.org/documentation/retrieve-metadata/rest-api/).
4. **PDF check.** Confirm that the authorized file opens as the intended paper, not a landing page. Record file digest, date/version from the title page, printed page and PDF page position. For a number, retain the table, row, column, unit and relevant footnote. Compare the extracted cell against the rendered page: a sign, column heading or denominator may not survive extraction. Record unread figures or scanned pages separately; if a decisive cell stays illegible, omit the estimate and request that page. [pypdf, Why Text Extraction is hard → Missing Semantic Layer](https://pypdf.readthedocs.io/en/stable/user/extract-text.html); see [article intake](research-article-intake.md).

## SEC filings: match the disclosure, not just the company

Start with the filer CIK. Keep the form, accession, filing URL, report period and filing date; distinguish the event date and public dissemination time when the design depends on either. Retain the identifier mapping valid on the date used to join to a security. Check historical submission files when the recent list does not reach the start of the window. Follow the [SEC fair-access instructions, “Fair access”](https://www.sec.gov/search-filings/edgar-search-assistance/accessing-edgar-data); use the official bulk release for a large authorized extract. [SEC API guide, Submissions and Bulk Data](https://www.sec.gov/search-filings/edgar-application-programming-interfaces).

For a numeric fact keep the taxonomy and tag, unit, instant or duration (start/end), accession, filing date, and amendment choice. The SEC aggregates non-custom, whole-entity facts; a missing API fact does not show that the company disclosed zero or had no segment information. Compare a sampled value with the filed statement, including its currency, scale, period and comparative column. If original and amended filings report different values, keep both; use the version public by the cutoff for a point-in-time question. If neither matches the intended context, withhold the observation. [SEC API guide, XBRL Data APIs, companyconcept and frames](https://www.sec.gov/search-filings/edgar-application-programming-interfaces).

## Financial text: from filing section to score

Link each passage to a specific accession or transcript version, section or speaker, and passage boundaries. Declare what the label means and whose perspective it represents. For example, the pinned [FinBERT configuration, `id2label`](https://huggingface.co/ProsusAI/finbert/raw/0bc2ac10dda6929bcb1f77ccc43c7ec5c424f031/config.json) defines positive, negative and neutral labels; it does not define monetary-policy stance. Record the tokenizer and model revisions, cleaning, segmentation, overlap and truncation. Retain input versus scored passage counts by document and period: failure to extract a section is not neutral tone.

Before the panel join, state whether each sentence, token or document gets equal weight; report the denominator after exclusions and prevent overlapping chunks from counting text twice. Trace a final firm-period score back to its contributing passages. Review excerpts across document types, periods and score extremes for failure cases; use a separate held-out labeled sample to estimate errors in the target population. Neither a plausible example nor agreement between two classifiers validates a causal interpretation. See the [text measurement audit](../../econ-research-design/references/text-measurement-inference.md) for validation and downstream inference.
