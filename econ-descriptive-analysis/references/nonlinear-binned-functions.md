# 非线性分仓图：对象、控制与推断

学习来源：[连享会 binsreg 完整正文](https://www.lianxh.cn/details/1928.html)，作者艾米丽，网站发布日期2026-09-08；另核对[官方Stata帮助](https://raw.githubusercontent.com/nppackages/binsreg/main/stata/binsreg.sthlp)及[On Binscatter作者论文](https://nppackages.github.io/references/Cattaneo-Crump-Farrell-Feng_2024_AER.pdf)相关控制、偏差与推断章节。正文已读不等于已验证全部证明或执行Stata/R/Python代码；本文为综合实践，不照录文章。

## 先确定曲线对象

- 无控制条件均值、控制调整后的部分线性函数、固定箱数粗化均值、导数和跨组差异是不同对象，写清再选图。
- 非线性 binscatter 中先机械线性残差化 X/Y 通常改变目标函数及原始 X 支撑；FWL 不能直接保证它还是原条件关系。作者框架在原始 X 分箱基函数上联合控制 W；这种部分线性设定不等于任意高维条件均值。
- 记录控制变量评价点及固定效应展示规范化，跨组比较使用可比较评价点与共同支撑，保留每箱人数、独特X数量和稀疏区标记。图形本身不识别因果剂量反应。

## 选箱与区间分开

- 自动 IMSE 选箱解决偏差—方差权衡，不保证连续函数推断自动有效；推断须按相应版本采取适当偏差处理及其额外不确定性。
- 固定箱数的区间若覆盖粗化对象，应按该对象解释，不能直接声称覆盖真实连续函数。
- 点态CI与统一置信带不同，二者都不是个体预测区间。曲线与直线相容不证明线性或外生性。
- 记录箱数/边界、p/s、权重、聚类、评价点、seed、实际样本及 mass points。支持图表先行探索，但不按最有利形状或p值隐藏其他实质规格。

## 实作前核查

所查官方 Stata help 使用 `dots(0 0)` 等空格格式，文章逗号式 `dots(0,0)` 未获独立执行确认。展示曲线阶数与推断阶数需分别核对，不能认为同一 cubic 设置在任何自动箱数下都有效。软件版本变化时重新读help；这份参考不承诺未运行命令可执行。
