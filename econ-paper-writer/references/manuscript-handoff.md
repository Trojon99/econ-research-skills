# From manuscript evidence to a review, response letter, or talk

Use this when a result leaves its original table, proof, or figure. The question at handoff is not just “Did the number survive?” It is “Will the next reader understand it as the same result?” Start with the supplied manuscript version and the requested role. A referee diagnoses; an author responds; a presenter explains. A request for any one of these does not authorize the others, new estimation, or disclosure of a confidential draft.

## Check the source before calling something an error

For each headline and each disputed passage, keep a short working record: **wording in the draft → version and exact location → object actually reported → disposition**. Locate a table by panel, row and column, not just page; distinguish the printed label from the PDF page index when they differ. For a proposition, locate the statement, the assumptions it invokes and the relevant step in the proof. Use the record for the handoff; it need not appear in the paper.

- **PDF evidence.** Use extracted text to find the passage, then read the decisive cell or symbol on the rendered page with its headers, notes and continuation pages. Two readers returning the same grid can still attach a value to the wrong header. A caption without cells, a broken minus sign, or a split bibliography entry is a reason to inspect the page, not an author error. If still illegible, request that page or the author’s table source. Keep an unread cell distinct from a printed blank, an omitted category and a reported zero. Do not fill any of them from a neighboring row.
- **Apparent numerical contradictions.** First match outcome, sample, period, weights, unit, denominator, transformation and aggregation. A pooled rate weights groups by their denominators; an unweighted average of group rates need not equal it. Different values alone do not establish a mistake. For a derived magnitude, retain the source of each input, the conversion and the rounding; check whether the difference could be due to displayed precision. Do not infer an exact value from the position of a marker in a plot.
- **Conflicting sources.** If two passages claim the same object but disagree after these checks, record both. This establishes an inconsistency, not which value is correct or why. Repetition in the abstract and conclusion does not break the tie. If the conflict changes the central claim, ask the author to resolve it before drafting that claim. If the source is merely unavailable, say what could not be checked and what would settle it.

## Referee comments and author responses

Write one independently actionable point per comment. Give the location, what was observed, its consequence for a named claim, and the least change that would address it. Distinguish **correction** (a demonstrated mismatch), **qualification** (the evidence permits a narrower interpretation), **suggestion** (useful but not needed for the claim), and **unverified** (missing evidence). Rank by consequence, not by label: a design qualification can overturn the headline while a confirmed typo may not matter. Do not infer that an unreported procedure was never performed. A verified clean comparison needs no invented objection; a new analysis is not necessary when correcting the label or narrowing the claim suffices.

In a response letter, keep each editor/referee point identifiable, including separately answerable requests within one comment. For each, record **what was requested → what was changed or declined, and why → exact location in the revised version**. If a new exhibit is claimed, open that exhibit and check that it answers the point. Distinguish completed changes from proposed work; a reasoned disagreement is a response, not a change to the paper. Check page and section references after the final render. Keep a private review separate from a letter for submission; neither an acceptance prediction nor a numerical paper score is required.

## Shorten the exhibit, not the claim

For an author talk, preserve the paper’s supported argument. For a discussion, distinguish the authors’ result from the discussant’s objection, calculation, or proposed test. Establish which time allocation belongs to the speaker rather than assuming a fixed share for questions. Order the material by what a listener needs: a comparison and outcome before the estimate, or the feasible choices and binding assumptions before a proposition. A counterfactual generated by a fitted model remains conditional in both title and script.

Reuse a legible exhibit. When cropping a panel or reducing a table, preserve the reference group, units, horizon, sample restrictions, uncertainty convention and any note or companion panel that changes its reading. Link the shortened version to the full display. If the figure must be redrawn, use underlying data or documented output, not pixel heights. Inspect the crop on its own and in the final render, including any overlays. For a poster, check the final dimensions against the organizer’s specifications and readability at the intended viewing distance; a successful build does not establish either. Read just the titles and then the spoken summary: if either implies causality where the paper reports a comparison, or drops a condition that changes the result, revise before delivery.

## Handoff acceptance

- **Can a second reader trace it?** Start with a headline in the *delivered* artifact and follow it back to the exact evidence. For an empirical exhibit offered with replication materials, identify the generating program and output where supplied. Mapping a program is not rerunning it; checking the arithmetic is not validating identification.
- **Does the response close the actual comment?** Check the revised text, not just the letter. Mark any open author decision and the smallest missing input. Do not mark an unanswered request complete just because the letter mentions it.
- **Is this the right file for this recipient?** For a named venue, distinguish initial submission, revision and camera-ready requirements. Use current official instructions supplied or verified within the task’s permissions; record their version/date and the applicable requirement. If anonymization is required, check the rendered file, metadata, supplementary material and exposed links. Check permissions before including data or source files. A template cannot establish the journal’s current disclosure policy, rights to redistribute data, or permission to submit.
